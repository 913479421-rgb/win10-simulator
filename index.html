💡 推荐使用 Tiny11 (Windows 11 精简版)

Tiny11 是基于 Windows 11 Pro 23H2 的精简版：

  • 安装后仅占 ~8GB 磁盘空间（完整版约 20GB+）
  • 已绕过 TPM 2.0 和 Secure Boot 限制
  • 移除不必要组件，模拟器中更稳定
  • 注意：64位系统，模拟器中运行较慢，建议耐心等待

搜索 "Tiny11 ISO 下载" 获取精简版镜像，推荐 tiny11 2311 x64 版本，下载后点击上方"选择 Windows ISO"导入。

使用说明

第一步：获取 Windows 10 ISO

  1. 点击「下载官方 Win10 ISO」按钮
  2. 在微软官网选择"Windows 10（多版本 ISO）"
  3. 选择"简体中文"，下载 32 位版本（推荐，内存占用更小）
  4. 文件名应为：Win10_22H2_Chinese_Simplified_x32v1.iso（约 4GB）

第二步：导入并安装

  1. 点击「创建虚拟磁盘」（建议 16GB 或 32GB）
  2. 点击「选择 Windows ISO」导入刚下载的镜像
  3. 在设置中开启「从光驱启动（安装系统时）」
  4. 点击「启动 Windows 10」，等待加载
  5. 点击「显示桌面」进入 Windows 安装界面
  6. 按照安装向导完成系统安装
  7. 安装完成后，关闭「从光驱启动」，从硬盘启动

提示：本应用使用 WebAssembly 在手机本地运行真实 x86 虚拟机， 消耗手机内存和存储。已安装系统后，再次打开网页会自动启动并显示 Windows 桌面。建议：

  • 内存分配 512MB（32位系统足够，减少手机负荷）
  • 磁盘大小 16GB（节省手机存储空间）
  • 连接电源使用，运行时耗电较快
  • 首次启动加载较慢，请耐心等待
  • 添加到主屏幕后可全屏离线运行
